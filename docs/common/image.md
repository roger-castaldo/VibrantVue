# Image

Used to supply a wrapped image component useful for sizing
[Bulma Docs](https://bulma.io/documentation/elements/image/)
## Props

| Name    | Type | Values | Default | Description |
| -------- | ------- | -------- | ------- | ------- |
| src | Ref\|string ||  | The source of the image|
| size | [ImageSizes](../enums.md#ImageSizes) |xsmall, small, medium, normal, large, xlarge, xxlarge| ImageSizes.normal | The size of the image|
| alt | string || '' | The alt content to use|
| is_loading | Ref\|boolean || undefined | Indicates if the image is loading and to render a skeleton style|
