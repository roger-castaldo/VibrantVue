# Title

## Props

| Name    | Type | Values | Default | Description |
| -------- | ------- | -------- | ------- | ------- |
| level | number || 1 | The title level 1-6|
| text | string || '' | The string content of the title|
| is_loading | Ref\|boolean || undefined | Indicates if the title is loading and to render a skeleton style|
## Slots

| Name    | Description |
| ------- | ------- |
| default|used when something more than text is desired|
